# Climate-Risk-Loss-Insurance-Model

##Overview

Developed a multi-factor climate risk model incorporating loss severity, event frequency and exposure to estimate and forecast staye-level financial risk using multiple real-world datasets including NOAA disaster events, FEMA declarations, Zillow home values and U.S Census data. Data sets were collected, cleaned merged and transformed into a unified dataset. Applied normalization techniques and machine learning to improve comparability and predictive performance.
A composite risk score was calculated using measures of total damage, event frequency and economic exposure. To improve comparability across states, normalized risk metrics were ind=troduced. A Random Forest regression model was developed to predict next-year risk,  scoring an R^2 of approximately 0.74, showcasing meaningful predictive capability.

The results show that property exposure and historical damage are the strongest drivers of future climate-related financial risk.
